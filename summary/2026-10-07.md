### Q1. Event Loop에 대해 알고 있으신가요? (이벤트 루프와 태스크 큐)

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/Esoolgnah/Frontend-Interview-Questions)

**모범 답변:**
자바스크립트는 싱글 스레드라 콜 스택이 하나뿐이며, 타이머·네트워크 같은 비동기 작업은 브라우저 Web API가 처리합니다.
작업이 끝나면 콜백이 태스크 큐(또는 마이크로태스크 큐)에 쌓이고, 이벤트 루프가 콜 스택이 비어 있을 때 큐에서 콜백을 꺼내 스택으로 옮겨 실행합니다.
덕분에 블로킹 없이 비동기 처리가 가능하지만, 콜 스택을 오래 점유하는 동기 작업은 UI를 멈추게 합니다.

### Q2. 마이크로태스크 큐와 태스크 큐에 대해서 말씀해주세요.

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/Esoolgnah/Frontend-Interview-Questions)

**모범 답변:**
태스크 큐(매크로태스크)에는 setTimeout, setInterval, 이벤트 콜백이, 마이크로태스크 큐에는 Promise의 then/catch/finally와 queueMicrotask가 들어갑니다.
이벤트 루프는 태스크 하나를 실행한 뒤 마이크로태스크 큐를 모두 비우고 나서 다음 태스크를 처리하므로, 마이크로태스크가 항상 먼저 실행됩니다.
```js
setTimeout(() => console.log('timeout'), 0);
Promise.resolve().then(() => console.log('promise'));
// promise → timeout
```

### Q3. Promise란 무엇이며 Callback function과 어떤 차이가 있나요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/junh0328/prepare_frontend_interview)

**모범 답변:**
Promise는 비동기 작업의 최종 완료(성공)나 실패와 그 결과값을 나타내는 객체이며, pending → fulfilled/rejected 상태를 가집니다.
콜백은 중첩되면 콜백 지옥과 분산된 에러 처리 문제가 생기지만, Promise는 then 체이닝과 catch로 흐름과 에러를 한곳에서 다룰 수 있습니다.
Promise.all, allSettled, race 등으로 여러 비동기 작업을 조합할 수 있는 점도 실무에서 유용합니다.

### Q4. async/await가 뭔가요? 기존의 Promise와는 어떤 차이가 있죠?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/junh0328/prepare_frontend_interview)

**모범 답변:**
async/await는 Promise 위에 만든 문법적 설탕으로, 비동기 코드를 동기 코드처럼 위에서 아래로 읽히게 해줍니다.
async 함수는 항상 Promise를 반환하고, await는 Promise가 settle될 때까지 해당 함수의 실행만 일시 중단합니다(스레드는 막지 않음).
에러는 try/catch로 처리하며, 서로 독립적인 작업은 `await Promise.all([...])`로 병렬 실행해야 불필요한 직렬 대기를 피할 수 있습니다.

### Q5. Ajax(비동기 통신)는 무엇이고 왜 사용하나요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/smee6/Frontend_Jr_Interview)

**모범 답변:**
Ajax는 페이지 전체를 새로고침하지 않고 서버와 데이터를 주고받아 화면 일부만 갱신하는 비동기 통신 방식입니다.
XMLHttpRequest나 fetch, Axios로 구현하며 보통 JSON을 주고받습니다.
불필요한 전체 리로드가 사라져 UX와 네트워크 효율이 좋아지고, 현대 SPA의 데이터 통신 기반이 됩니다.
