### Q1. 웹 접근성이란 무엇인가요?

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://github.com/junh0328/prepare_frontend_interview)

**모범 답변:**
웹 접근성(Web Accessibility)은 신체적·인지적 제약과 관계없이 모든 사용자가 웹 콘텐츠를 동등하게 이용할 수 있도록 보장하는 것입니다. 스크린 리더 사용자, 키보드만으로 조작하는 사용자, 색약 사용자 등을 고려해 시맨틱 마크업, 대체 텍스트, 충분한 색상 대비, 키보드 포커스 순서 등을 지켜야 합니다. WCAG(Web Content Accessibility Guidelines)가 국제 표준으로 통용되며, 국내 공공기관 프로젝트에서는 웹 접근성 인증(KWCAG) 획득이 요구사항으로 자주 등장합니다.

### Q2. 웹 접근성에 맞는 마크업 예시를 몇 가지 들어 설명해주세요.

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://github.com/junh0328/prepare_frontend_interview)

**모범 답변:**
이미지에는 `alt` 속성으로 대체 텍스트를 제공하고, 폼 요소는 `label`과 `for`/`id`로 명확히 연결해야 합니다. 시맨틱 태그(`header`, `nav`, `main`, `footer` 등)를 사용해 스크린 리더가 문서 구조를 파악할 수 있게 합니다. 클릭 가능한 요소는 `div`가 아닌 `button`처럼 키보드 포커스와 Enter/Space 조작이 가능한 요소를 사용하고, 필요 시 `aria-label`, `role` 속성으로 보조 정보를 추가합니다.

### Q3. 시맨틱 태그란 무엇이며 왜 사용하나요?

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://github.com/junh0328/prepare_frontend_interview)

**모범 답변:**
시맨틱 태그는 `div`, `span`처럼 의미 없는 태그 대신 `header`, `nav`, `article`, `section`, `footer`처럼 콘텐츠의 의미와 구조를 드러내는 HTML 태그입니다. 브라우저와 스크린 리더가 문서 구조를 정확히 해석할 수 있어 웹 접근성이 향상되고, 검색엔진이 콘텐츠 중요도를 파악하기 쉬워져 SEO에도 유리합니다. 또한 협업 시 코드 가독성과 유지보수성이 좋아집니다.

### Q4. CSS position 속성(static/relative/fixed/absolute)의 차이를 설명해주세요.

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://github.com/Esoolgnah/Frontend-Interview-Questions)

**모범 답변:**
`static`은 기본값으로 문서 흐름을 따르며 top/left 등이 적용되지 않습니다. `relative`는 자신의 원래 위치를 기준으로 오프셋을 적용하되 문서 흐름상 공간은 그대로 차지합니다. `absolute`는 가장 가까운 `position`이 static이 아닌 조상 요소를 기준으로 배치되며 문서 흐름에서 빠집니다. `fixed`는 뷰포트를 기준으로 고정되어 스크롤해도 위치가 변하지 않습니다. 모달, 툴팁, sticky header 구현 시 자주 활용됩니다.

### Q5. CSS Box model에서 width 값이 차지하는 실제 크기는 어떻게 계산되나요?

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://github.com/Esoolgnah/Frontend-Interview-Questions)

**모범 답변:**
기본값인 `box-sizing: content-box`에서는 `width`가 콘텐츠 영역만을 의미하며, 실제 요소 크기는 `width + padding + border`를 더한 값이 됩니다. 반면 `box-sizing: border-box`를 적용하면 `width` 값 안에 padding과 border가 포함되어 지정한 width가 곧 요소의 전체 너비가 됩니다. 레이아웃 계산을 예측 가능하게 하기 위해 실무에서는 보통 `* { box-sizing: border-box; }`를 전역으로 적용합니다.
