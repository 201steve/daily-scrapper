### Q1. Promise와 Callback의 차이는 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://devowen.com/276)

**모범 답변:**
Callback은 비동기 작업의 결과를 콜백 함수 인자로 전달받는 방식으로, 여러 비동기 작업을 순차 연결하면 콜백이 중첩되어 콜백 지옥이 발생하기 쉽습니다. Promise는 비동기 작업의 상태(pending/fulfilled/rejected)를 객체로 캡슐화해 `.then()`/`.catch()` 체이닝으로 흐름을 평탄하게 작성할 수 있습니다. 에러 처리도 `.catch()` 한 곳에서 일괄 처리할 수 있어 콜백 방식보다 예외 처리가 명확합니다.

### Q2. async/await은 어떻게 동작하며 Promise와 비교했을 때 장점은 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://velog.io/@okxooxoo/%EC%9E%90%EC%A3%BC-%EB%93%B1%EC%9E%A5%ED%95%98%EB%8A%94-%ED%94%84%EB%A1%A0%ED%8A%B8%EC%97%94%EB%93%9C-%EA%B8%B0%EC%88%A0-%EB%A9%B4%EC%A0%91-%EC%A7%88%EB%AC%B8-%EC%A0%95%EB%A6%AC-JS%ED%8E%B8)

**모범 답변:**
async 함수는 항상 Promise를 반환하며, 함수 내부의 await 키워드는 Promise가 처리(resolve/reject)될 때까지 실행을 일시 중단시킵니다. 이를 통해 비동기 코드를 동기 코드처럼 순차적으로 읽고 쓸 수 있어 가독성과 유지보수성이 크게 향상됩니다. 에러 처리도 try/catch로 동기 코드와 동일하게 다룰 수 있습니다.
```js
async function fetchUser() {
  try {
    const res = await fetch('/api/user');
    return await res.json();
  } catch (e) {
    console.error(e);
  }
}
```

### Q3. 이벤트 루프(Event Loop)는 어떻게 동작하나요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://velog.io/@holim0/Front-End-%EB%A9%B4%EC%A0%91-%EC%A7%88%EB%AC%B8-%EB%8C%80%EB%B9%84-Part5-JavaScript-%EC%9D%B4%EB%B2%A4%ED%8A%B8-%EB%A3%A8%ED%94%84-%EB%B9%84%EB%8F%99%EA%B8%B0-%EC%B2%98%EB%A6%AC)

**모범 답변:**
JS는 싱글 스레드로 Call Stack에서 코드를 순차 실행하며, setTimeout·fetch 같은 비동기 작업은 Web API로 위임됩니다. 작업이 완료되면 콜백이 Task Queue(매크로태스크) 또는 Microtask Queue(프로미스 등)에 쌓입니다. Event Loop는 Call Stack이 완전히 비었을 때 Microtask Queue를 모두 비운 뒤, Task Queue의 콜백을 하나씩 Call Stack으로 옮겨 실행합니다.

### Q4. 콜백 지옥(Callback Hell)이란 무엇이며 어떻게 해결할 수 있나요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://devowen.com/276)

**모범 답변:**
콜백 지옥은 여러 비동기 작업을 순차 처리하기 위해 콜백 함수를 계속 중첩하면서 코드가 깊어지고 가독성·유지보수성이 나빠지는 현상입니다. Promise 체이닝(`.then()`)으로 중첩을 평탄화하거나, async/await으로 동기 코드처럼 작성해 해결할 수 있습니다. 콜백을 작은 이름 있는 함수로 분리해 재사용하는 것도 중첩을 줄이는 방법입니다.

### Q5. Microtask Queue와 Macrotask(Task) Queue의 차이는 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://velog.io/@honeysuckle/%EC%8B%A0%EC%9E%85-%ED%94%84%EB%A1%A0%ED%8A%B8%EC%97%94%EB%93%9C-%EB%A9%B4%EC%A0%91-%EC%A7%88%EB%AC%B8-%EB%AA%A8%EC%9D%8C)

**모범 답변:**
Macrotask(Task) Queue에는 setTimeout, setInterval, I/O 등의 콜백이 쌓이고, Microtask Queue에는 Promise의 `.then/.catch/.finally`, queueMicrotask 등의 콜백이 쌓입니다. Event Loop는 매크로태스크를 하나 실행한 뒤, 다음 매크로태스크로 넘어가기 전에 Microtask Queue를 완전히 비웁니다. 따라서 Promise 콜백이 setTimeout 콜백보다 항상 먼저 실행되며, 이 우선순위는 실행 순서를 예측할 때 중요합니다.
