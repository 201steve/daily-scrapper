### Q1. interface와 type의 차이점은 무엇인가요?

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://velog.io/@keynene/TypeScript-type과-interface-사용법과-공통점-및-차이점)

**모범 답변:**
interface는 객체 구조 정의에 특화되어 있고, 같은 이름으로 선언하면 자동으로 병합(Declaration Merging)되며 extends로 확장합니다. type은 원시값·유니언·튜플 등 더 넓은 타입을 정의할 수 있지만 중복 선언 시 에러가 발생하고, 확장은 교차 타입(&)으로 처리합니다. TypeScript 팀은 객체 타입을 정의할 때 기본적으로 interface 사용을 권장하며, 유니언 타입이나 인덱스 시그니처가 필요할 때만 type을 쓰도록 권장합니다.

### Q2. any와 unknown의 차이는 무엇인가요?

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://velog.io/@minj9_6/개발자로서-첫-면접-질문-정리)

**모범 답변:**
any는 타입 검사를 사실상 포기하는 타입으로, 어떤 값이든 자유롭게 할당·사용할 수 있어 컴파일 타임 타입 안전성을 잃습니다. unknown은 모든 값을 할당받을 수는 있지만, 실제로 사용하려면 타입 가드나 타입 단언으로 좁혀야만 합니다. 따라서 외부 API 응답처럼 타입을 확신할 수 없는 값에는 any 대신 unknown을 사용해 안전하게 검증한 뒤 사용하는 것이 권장됩니다.

### Q3. Union 타입과 Intersection 타입의 차이는 무엇인가요?

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://velog.io/@flutter_0807/프론트엔드-면접-질문-리스트와-답)

**모범 답변:**
Union(`|`) 타입은 "A 또는 B"처럼 여러 타입 중 하나를 허용할 때 사용하며, 함수 인자가 여러 형태를 받을 수 있게 합니다. Intersection(`&`) 타입은 "A 그리고 B"처럼 여러 타입을 모두 만족하는 하나의 타입을 만들 때 사용하며, 주로 객체 타입을 합성할 때 활용됩니다. 예: `type Admin = User & { role: 'admin' }`. Union은 타입 좁히기(narrowing)와 함께 조건 분기 로직에서 자주 쓰입니다.

### Q4. 제네릭(Generic)이란 무엇이고 어떻게 활용하나요?

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://github.com/Jeontaeyun/TypeScript/blob/master/SUMMARY.md)

**모범 답변:**
제네릭은 함수·클래스·인터페이스를 호출하는 시점에 타입을 결정할 수 있게 해주는 기능으로, 특정 타입에 종속되지 않는 재사용 가능한 코드를 작성할 때 사용합니다. 예: `function identity<T>(arg: T): T { return arg; }`처럼 입력과 출력의 타입 관계를 유지하면서 다양한 타입에 대응할 수 있습니다. 실무에서는 API 응답 타입, 커스텀 훅, 공통 컴포넌트 props 등에 폭넓게 활용됩니다.
