### Q1. Virtual DOM이란 무엇이며, Real DOM과의 차이는 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [medium.com/@heoh06](https://medium.com/@heoh06/%EB%A6%AC%EC%95%A1%ED%8A%B8-%EB%A6%AC%EC%95%A1%ED%8A%B8-%EB%A9%B4%EC%A0%91%EC%A7%88%EB%AC%B8-1c6050d87c8b)

**모범 답변:**
Virtual DOM은 Real DOM의 경량 in-memory 복사본입니다. 상태가 변경되면 React는 새로운 Virtual DOM 트리를 생성하고, 이전 트리와 비교(diffing)하여 변경된 최소 부분만 Real DOM에 반영합니다. Real DOM 직접 조작은 레이아웃 재계산·리페인트를 유발해 비용이 크지만, Virtual DOM을 거치면 DOM 접근을 일괄 최소화할 수 있습니다.

### Q2. 함수형 컴포넌트와 클래스형 컴포넌트의 차이는 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [velog.io/@dnr6054](https://velog.io/@dnr6054/fe-interview-React)

**모범 답변:**
클래스형 컴포넌트는 `class` 문법과 `render()` 메서드를 사용하며, 생명주기 메서드로 사이드이펙트를 관리합니다. 함수형 컴포넌트는 단순 함수로 선언하며, React 16.8+ Hooks(`useState`, `useEffect` 등)로 동일한 기능을 구현합니다. 함수형 컴포넌트는 코드가 간결하고 테스트·재사용이 쉬우며, 공식 권장 방식입니다.

### Q3. useMemo와 useCallback의 차이는 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [velog.io/@developer-sora](https://velog.io/@developer-sora/%ED%94%84%EB%A1%A0%ED%8A%B8%EC%97%94%EB%93%9C-%EB%A9%B4%EC%A0%91-%EC%A7%88%EB%AC%B8-%EC%A0%95%EB%A6%AC-Part1CS-JSReact)

**모범 답변:**
`useMemo`는 **계산 결과값**을 메모이제이션하고, `useCallback`은 **함수 참조**를 메모이제이션합니다.
```js
const memoValue = useMemo(() => expensiveCalc(a, b), [a, b]);
const memoFn    = useCallback(() => doSomething(a), [a]);
```
자식 컴포넌트에 콜백을 props로 전달할 때 `useCallback`으로 참조 안정성을 유지해야 `React.memo`와 조합해 불필요한 리렌더링을 방지할 수 있습니다.

### Q4. React 컴포넌트가 리렌더링되는 조건은 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [socaeri.com](https://socaeri.com/entry/%ED%94%84%EB%A1%A0%ED%8A%B8%EC%97%94%EB%93%9C-FE-%EA%B8%B0%EC%88%A0%EB%A9%B4%EC%A0%91-%EB%B3%B5%EA%B8%B0-%EB%AA%A8%EC%9D%8C)

**모범 답변:**
리렌더링 조건은 크게 네 가지입니다: ① `state` 변경(`setState` 호출), ② 부모로부터 받은 `props` 변경, ③ `Context` 값 변경, ④ 부모 컴포넌트 리렌더링(props 변경 없어도 기본 재렌더). 불필요한 리렌더링은 `React.memo`, `useMemo`, `useCallback`으로 억제할 수 있습니다. `useState`와 `useReducer`만이 렌더링을 트리거하는 Hook입니다.

### Q5. useEffect와 useLayoutEffect의 차이는 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [velog.io/@dnr6054](https://velog.io/@dnr6054/fe-interview-React)

**모범 답변:**
`useEffect`는 **비동기적**으로, 브라우저가 화면을 paint한 **후** 실행됩니다. `useLayoutEffect`는 **동기적**으로, DOM이 업데이트된 직후 paint **전**에 실행됩니다. 레이아웃 측정이나 DOM 조작이 화면 깜빡임 없이 즉시 반영되어야 할 때 `useLayoutEffect`를 사용하고, 그 외 데이터 페칭·구독 설정은 `useEffect`를 권장합니다.
