### Q1. CSS margin과 padding의 차이를 설명해주세요.

> **importance_score**: 2/5 | **빈출**: high | **출처**: [junh0328/prepare_frontend_interview](https://github.com/junh0328/prepare_frontend_interview), [Esoolgnah/Frontend-Interview-Questions](https://github.com/Esoolgnah/Frontend-Interview-Questions), [soojjung/frontend-interview](https://github.com/soojjung/frontend-interview)

**모범 답변:**
margin은 요소 외부의 여백으로 다른 요소와의 간격을 만들며 배경이 적용되지 않는다. padding은 요소 내부의 여백으로 콘텐츠와 border 사이 간격을 만들고 배경색/이미지가 그대로 적용된다. box-sizing: border-box를 쓰면 padding과 border가 지정한 width/height 안에 포함되어 계산이 예측 가능해진다. 인접한 블록 요소 사이에서는 margin이 상쇄(margin collapse)되는 현상이 발생할 수 있지만 padding에는 없다.

### Q2. CSS position 속성(static/relative/absolute/fixed)의 차이를 설명해주세요.

> **importance_score**: 2/5 | **빈출**: high | **출처**: [junh0328/prepare_frontend_interview](https://github.com/junh0328/prepare_frontend_interview), [Esoolgnah/Frontend-Interview-Questions](https://github.com/Esoolgnah/Frontend-Interview-Questions), [soojjung/frontend-interview](https://github.com/soojjung/frontend-interview)

**모범 답변:**
static은 기본값으로 문서 흐름을 따르고 top/left 등 오프셋이 적용되지 않는다. relative는 원래 자리를 기준으로 이동하지만 문서 흐름상 자리는 그대로 차지한다. absolute는 static이 아닌 가장 가까운 조상을 기준으로 배치되며 문서 흐름에서 빠진다. fixed는 뷰포트를 기준으로 고정되어 스크롤해도 위치가 변하지 않는다.

### Q3. CSS Box model에서 width 값이 차지하는 영역은 어떻게 되나요?

> **importance_score**: 2/5 | **빈출**: high | **출처**: [junh0328/prepare_frontend_interview](https://github.com/junh0328/prepare_frontend_interview), [Esoolgnah/Frontend-Interview-Questions](https://github.com/Esoolgnah/Frontend-Interview-Questions), [soojjung/frontend-interview](https://github.com/soojjung/frontend-interview)

**모범 답변:**
기본값(box-sizing: content-box)에서 width는 콘텐츠 영역만 의미하며, 실제 렌더링 너비는 width + padding + border의 합이 된다. box-sizing: border-box로 설정하면 padding과 border가 width 안에 포함되어 지정한 값이 곧 전체 너비가 된다. 실무에서는 레이아웃을 예측 가능하게 만들기 위해 `* { box-sizing: border-box; }`를 전역으로 많이 사용한다. margin은 box-sizing과 무관하게 항상 별도로 더해진다.

### Q4. flex를 사용하는 이유는 무엇인가요?

> **importance_score**: 2/5 | **빈출**: high | **출처**: [junh0328/prepare_frontend_interview](https://github.com/junh0328/prepare_frontend_interview), [soojjung/frontend-interview](https://github.com/soojjung/frontend-interview)

**모범 답변:**
flex는 컨테이너 안 아이템을 한 축(행 또는 열) 기준으로 정렬·분배하기 쉽게 해주어 float나 position보다 반응형 레이아웃 구현이 간단하다. justify-content, align-items 등으로 중앙 정렬이나 균등 분배 같은 배치를 직관적으로 처리할 수 있다. flex-grow/shrink/basis로 아이템 크기를 동적으로 조절해 다양한 화면 크기에 대응하기 좋다. 다차원(행+열) 레이아웃이 필요할 땐 Grid가 더 적합하다.

### Q5. display 속성(block, inline, inline-block, none)의 차이를 설명해주세요.

> **importance_score**: 2/5 | **빈출**: high | **출처**: [junh0328/prepare_frontend_interview](https://github.com/junh0328/prepare_frontend_interview), [soojjung/frontend-interview](https://github.com/soojjung/frontend-interview)

**모범 답변:**
block은 한 줄 전체를 차지하며 width/height와 margin/padding이 상하좌우 모두 적용된다(div, p 등). inline은 콘텐츠 크기만큼만 차지하고 줄바꿈이 없으며 width/height와 상하 margin이 적용되지 않는다(span, a 등). inline-block은 줄바꿈 없이 배치되면서도 width/height와 margin/padding이 모두 적용된다. none은 요소를 렌더링 트리에서 제거해 공간조차 차지하지 않으며, 이는 visibility: hidden과 다르다.
