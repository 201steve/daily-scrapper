### Q1. 이벤트 루프(Event Loop)란 무엇이며 어떻게 동작하나요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [Esoolgnah/Frontend-Interview-Questions](https://github.com/Esoolgnah/Frontend-Interview-Questions)

**모범 답변:**
JavaScript는 싱글 스레드 언어이지만, 이벤트 루프를 통해 비동기 작업을 처리합니다. 이벤트 루프는 콜 스택(Call Stack)이 비어 있을 때 콜백 큐(Callback Queue)에서 작업을 꺼내 실행합니다. `setTimeout` 같은 비동기 콜백은 Web API에서 처리된 후 태스크 큐에, `Promise.then` 콜백은 마이크로태스크 큐에 들어가며, 마이크로태스크가 태스크보다 항상 먼저 처리됩니다.

### Q2. async/await은 무엇이며 Promise와 어떤 차이점이 있나요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [junh0328/prepare_frontend_interview](https://github.com/junh0328/prepare_frontend_interview)

**모범 답변:**
`async/await`는 Promise를 기반으로 동작하는 ES2017 문법으로, 비동기 코드를 동기 코드처럼 읽기 쉽게 작성할 수 있게 해줍니다. `async` 함수는 항상 Promise를 반환하고, `await`는 Promise가 settled될 때까지 함수 실행을 일시 중단합니다. 에러 처리는 Promise의 `.catch()` 대신 `try/catch` 블록으로 하며, 가독성과 디버깅 측면에서 유리합니다.
```js
async function fetchData() {
  try {
    const res = await fetch('/api/data');
    return await res.json();
  } catch (e) {
    console.error(e);
  }
}
```

### Q3. Promise란 무엇이며, pending / fulfilled / rejected 세 가지 상태를 설명해주세요

> **importance_score**: 4/5 | **빈출**: high | **출처**: [junh0328/prepare_frontend_interview](https://github.com/junh0328/prepare_frontend_interview)

**모범 답변:**
Promise는 비동기 작업의 최종 완료 또는 실패를 나타내는 객체입니다. 세 가지 상태를 가집니다: **pending**(대기 — 아직 처리 중), **fulfilled**(이행 — 성공적으로 완료), **rejected**(거부 — 실패). 한번 settled(fulfilled 또는 rejected)되면 상태가 변경되지 않으며(불변), `.then()`으로 성공 결과를, `.catch()`로 실패를 처리합니다.

### Q4. 마이크로태스크 큐(Microtask Queue)와 태스크 큐(Task Queue)의 차이점과 우선순위를 설명해주세요

> **importance_score**: 4/5 | **빈출**: high | **출처**: [Esoolgnah/Frontend-Interview-Questions](https://github.com/Esoolgnah/Frontend-Interview-Questions)

**모범 답변:**
태스크 큐(매크로태스크 큐)에는 `setTimeout`, `setInterval`, I/O 콜백 등이 들어가고, 마이크로태스크 큐에는 `Promise.then/catch`, `queueMicrotask`, `MutationObserver` 콜백이 들어갑니다. 콜 스택이 비워지면 이벤트 루프는 **마이크로태스크 큐를 먼저 완전히 비운 뒤** 태스크 큐에서 하나를 처리합니다. 따라서 `Promise.then`은 `setTimeout(fn, 0)`보다 항상 먼저 실행됩니다.

### Q5. 클로저(Closure)란 무엇이며 어떻게 활용되나요? 메모리에 미치는 영향은?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [junh0328/prepare_frontend_interview](https://github.com/junh0328/prepare_frontend_interview)

**모범 답변:**
클로저는 함수가 자신이 선언된 렉시컬 스코프(외부 함수의 변수)를 기억하고 접근할 수 있는 현상입니다. 데이터 은닉(private 변수 구현), 커링, React의 `useState` 훅 내부 구현 등에 활용됩니다. 단, 클로저가 외부 변수를 참조하는 한 GC가 해당 메모리를 회수하지 않으므로, 불필요한 클로저를 남기면 메모리 누수가 발생할 수 있습니다.
```js
function counter() {
  let count = 0; // 외부 변수를 기억
  return () => ++count;
}
const inc = counter();
inc(); // 1, inc(); // 2
```
