### Q1. 자바스크립트에서 비동기 처리를 위한 방법(콜백, Promise, async/await)을 설명해주세요.

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/Esoolgnah/Frontend-Interview-Questions/blob/main/Notes/important-4/async-in-javascript.md)

**모범 답변:**
JS의 비동기 처리는 콜백 → Promise → async/await 순으로 발전했다. 콜백은 함수 인자로 전달되어 완료 후 실행되지만 중첩되면 콜백 지옥이 발생한다. Promise는 비동기 작업의 성공/실패를 객체로 추상화해 `.then`/`.catch`로 처리하며 체이닝이 가능하다. async/await는 Promise 기반 문법으로, async 함수는 항상 Promise를 반환하고 await로 완료를 동기 코드처럼 기다릴 수 있어 가독성이 좋다.

---

### Q2. Promise란 무엇이며 콜백 함수와의 차이는 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/smee6/Frontend_Jr_Interview)

**모범 답변:**
Promise는 비동기 작업의 미래 결과(성공 또는 실패)를 나타내는 객체로, pending/fulfilled/rejected 상태를 가진다. callback은 함수를 인자로 넘겨 제어권을 위임하는 방식으로, 중첩되면 콜백 지옥이 발생하고 에러 처리가 분산된다. Promise는 `.then`/`.catch` 체이닝과 `Promise.all` 등으로 여러 비동기 작업을 명시적으로 다룰 수 있어 가독성과 에러 처리가 개선된다.

---

### Q3. 콜백 지옥(Callback Hell)이란 무엇이며 이를 해결하는 방법은 무엇인가요?

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/smee6/Frontend_Jr_Interview)

**모범 답변:**
콜백 지옥은 비동기 콜백이 중첩되며 코드 들여쓰기가 깊어지고 가독성·유지보수성이 떨어지는 현상이다. 주로 이벤트 처리나 서버 통신 같은 연쇄적 비동기 작업에서 발생한다. Promise의 체이닝(`.then`)으로 평탄화하거나, ES8의 async/await 문법을 사용해 동기 코드처럼 작성하면 해결할 수 있다.

---

### Q4. async/await의 사용 방법과 Promise와의 관계를 설명해주세요.

> **importance_score**: 4/5 | **빈출**: high | **출처**: [링크](https://github.com/smee6/Frontend_Jr_Interview)

**모범 답변:**
함수 앞에 `async`를 붙이면 해당 함수는 항상 Promise를 반환한다. 함수 내부에서 비동기 작업이 필요한 지점에 `await`를 붙이면 Promise가 처리될 때까지 기다렸다가 결과값을 반환한다. try/catch와 함께 사용하면 에러 처리를 동기 코드처럼 직관적으로 작성할 수 있어 Promise 체이닝보다 가독성이 좋다.
```js
async function getUser() {
  try {
    const res = await fetch('/api/user');
    return await res.json();
  } catch (e) {
    console.error(e);
  }
}
```

### Q5. 이벤트 루프(Event Loop)란 무엇이며 자바스크립트의 비동기 처리를 어떻게 가능하게 하나요?

> **importance_score**: 3/5 | **빈출**: high | **출처**: [링크](https://github.com/Esoolgnah/Frontend-Interview-Questions/blob/main/Notes/important-4/event-loop.md)

**모범 답변:**
JS는 싱글 스레드지만 이벤트 루프 덕분에 비동기 작업을 효율적으로 처리한다. 콜스택이 실행 중인 함수를 LIFO로 처리하고, setTimeout·AJAX 같은 비동기 작업은 Web API로 위임된 뒤 완료되면 콜백 큐(매크로태스크)나 마이크로태스크 큐에 쌓인다. 이벤트 루프는 콜스택이 비어있을 때 마이크로태스크 큐를 모두 비운 뒤 콜백 큐의 작업을 콜스택으로 옮겨 실행한다.
